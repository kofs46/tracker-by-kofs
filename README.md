# 🚀 KOFSLedger • Smart Financial & Project Operating System

**KOFSLedger** is a cutting-edge, web-based financial management and project operating system tailored for personal and professional multi-account tracking, project budgeting, debt management, and real-time cash flow auditing.

---

## ✨ Key Features & Capabilities

* **Multi-Account & Wallet Management**: Track balances across multiple MFS providers (*bKash, Nagad, Rocket, Upay, etc.*), Commercial Banks (*DBBL, BRAC, EBL, IBBL*), and Cash in Hand.
* **Fund Transfers & Project Fund Shifting**: Seamlessly transfer money between accounts or shift budget funds between active projects with real-time balance calculations.
* **Active Projects & Purpose Ledger**: Manage project budget ceilings, monitor inflow/outflow, and record line-item expenses with granular precision.
* **Lent & Debt Tracker**: Unique phone-identifier-based debt tracking system allowing consolidated views, automated partial/full repayments, and a complete borrower timeline history ledger.
* **Advanced Balance Flow Auditing**: Every transaction tracks previous balance, transaction amount, and resulting balance in an immutable historical ledger.
* **Interactive Visual Analytics**: Dynamic Chart.js integration showing project cost distributions and monthly/daily cash flow burn rates.
* **Secure Authentication & Profile Protection**: JWT-based authentication with encrypted password hashing, custom avatar uploads, and 6-digit PIN password recovery.
* **Official Statement Printing**: One-click printable financial summary statements formatted cleanly for auditing.

---

## 🛠️ Tech Stack

* **Frontend**: HTML5, Tailwind CSS, JavaScript (Vanilla ES6+), FontAwesome, Chart.js
* **Backend**: Node.js, Express.js (Netlify Serverless Functions)
* **Database**: MongoDB & Mongoose
* **Security**: BcryptJS, JSON Web Tokens (JWT)
