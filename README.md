## ✨ Key Features & Capabilities

* **Multi-Account & Wallet Management**: Track balances across multiple MFS providers (*bKash, Nagad, Rocket, Upay, etc.*), Commercial Banks (*DBBL, BRAC, EBL, IBBL*), and Cash in Hand[cite: 10].
* **Fund Transfers & Project Fund Shifting**: Seamlessly transfer money between accounts or shift budget funds between active projects with real-time balance calculations[cite: 10].
* **Active Projects & Purpose Ledger**: Manage project budget ceilings, monitor inflow/outflow, and record line-item expenses with granular precision[cite: 10].
* **Lent & Debt Tracker**: Unique phone-identifier-based debt tracking system allowing consolidated views, automated partial/full repayments, and a complete borrower timeline history ledger[cite: 10].
* **Advanced Balance Flow Auditing**: Every transaction tracks previous balance, transaction amount, and resulting balance in an immutable historical ledger[cite: 10].
* **Date-Range Statement Filtering**: Filter and audit all transactions, credits, and debits by custom start/end dates alongside account and project filters.
* **Interactive Visual Analytics**: Dynamic Chart.js integration showing project cost distributions and monthly/daily cash flow burn rates[cite: 10].
* **Progressive Web App (PWA) Ready**: Fully installable on mobile devices (Android/iOS) and desktops with offline service worker support.
* **Secure Authentication & Profile Protection**: JWT-based authentication with encrypted password hashing, custom avatar uploads, and 6-digit PIN password recovery[cite: 10].
* **Official Statement Printing**: One-click printable financial summary statements formatted cleanly for auditing[cite: 10].
